# AI_NOTES

Использовал Claude Code (CLI) и Codex для ревью и кода. Вот три моих запроса дословно:

> погляди дали на ИИ ревью проект посмотри редми

> делай все через енумы

> что думаешь делать? мне не нравится миграции на скл выражениях

Codex ошибся: написал, что запрос без токена и без `Accept` вернёт 401. Claude проверил исходники Laravel 13.39.0: middleware сначала вызывает несуществующий `route('login')`, поэтому выходит 500. Ошибки Claude нашёл Codex: `timestampTz` не заменяет перевод времени в UTC, а `today()` ломается и для Москвы. Тест поймал ещё один случай: время с `Z` сначала не проходило `date_format`.

Я сам выбрал вариант без SQL в миграциях: `lockForUpdate()` мне проще объяснить. Попросил использовать enum и оставил коммиты и отправку репозитория за собой. Исходники Laravel, тесты в Docker и API через curl проверяли агенты; я смотрел их вывод и сверял результат с README.
